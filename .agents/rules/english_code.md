# English-Only Code Output

All code generated by the agent must strictly follow these English-only guidelines:

- **Naming**: All variable names, function names, class names, constants, and database fields must be in English.
- **Comments**: All code comments and docstrings must be written in English.
- **Strings**: Hardcoded strings that are visible to the developer (like log messages, error descriptions, or internal IDs) must be in English.
- **Documentation**: Any accompanying documentation or architectural explanations related to the code must be in English.
- **Consistency**: Maintain English as the primary language for all technical implementations, regardless of the user's input language.
